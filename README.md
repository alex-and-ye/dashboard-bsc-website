# BSC Strategy Dashboard

Статичный сайт для построения dashboard ключевых показателей реализации стратегии по CSV-файлу DashboardDX.

## Как использовать

1. Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages.
2. Загрузите CSV-файл с колонками `Ветка BSC`, `Перспектива`, `KPI`, `Инициатива`, `Дата`, `План`, `Факт`, `Δ`, `Домен`.
3. Нажмите `Сгенерировать`, чтобы построить dashboard.
4. Нажмите `Очистить`, чтобы сбросить файл и графики.

## GitHub Pages

Сайт не требует backend и сборки. Для публикации включите GitHub Pages в настройках репозитория и выберите ветку с файлами проекта, обычно `main` и папку `/root`.

## Технические детали

- CSV обрабатывается локально в браузере, файл не отправляется на сервер.
- Графики строятся через Chart.js.
- CSV парсится через Papa Parse.
- Поддерживаются русские числовые форматы с запятой, пробелами и неразрывными пробелами.
